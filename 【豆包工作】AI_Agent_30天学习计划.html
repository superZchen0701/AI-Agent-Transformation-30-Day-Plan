一、现有资料评估与补充建议

1.1 现有资料评估

📘 资料一：Hello-Agents《从零开始构建智能体》

Datawhale 出品的系统性 Agent 教程，共 5 大部分 16 章，是目前国内最完整的 Agent 入门到进阶开源教程之一。

覆盖范围：

  • 基础篇：Agent 定义、历史、LLM 基础与局限
  • 构建篇：ReAct / Plan-and-Solve / Reflection 范式手写实现、低代码平台（Coze/Dify/n8n）、主流框架（AutoGen/AgentScope/LangGraph）
  • 高级篇：Memory 与 RAG、上下文工程、MCP/A2A/ANP 通信协议、Agentic RL
  • 实战篇：智能旅行助手、深度研究 Agent、赛博小镇三大综合项目

优点体系完整、理论与实战并重、中文友好、有可运行代码

不足偏 Python 技术栈；Harness 工程化层面（稳定性、成本控制、沙箱、插件化架构）涉及较浅

定位：第 1-2 周核心教材，重点学第 1-6 章和第 8-10 章

📗 资料二：deepseek-harness

DeepSeek 开源的 Agent 运行时框架，核心理念是"一切皆插件"（Everything is a Plugin），基于 Cordis（Koishi.js 生态的依赖注入框架）构建，技术栈为 TypeScript。

核心架构（由内到外）：

  • Agent Loop 层：任务推进循环，控制何时请求模型、何时调用工具、何时结束
  • Agent Runtime 层：Agent 注册、沙箱、模型/工具调用 Session 管理、交互模式
  • 插件层：模型适配器、工具注册表、会话/存储、沙箱/权限、调度/任务，全部可插拔
  • 入口层：Web、Headless、ACP、SDK 统一进入运行核心

优点直接对标 Agent Harness 岗位；TypeScript 技术栈对你前端出身是巨大差异化优势；架构设计先进

不足学习门槛较高，需先有 Agent 基础；文档精简；项目较新社区教程少

定位：第 3 周核心研读对象，先跑通再读源码，最终开发自定义插件

💡 关键洞察：deepseek-harness 是 TypeScript 写的，这意味着你可以比 Python 背景的候选人更快读懂源码、贡献插件。这是面试中的差异化卖点，务必在第 3 周深耕。

九、学习方法与坚持策略

9.1 解决"看着看着没目标"的核心方法

你现在的问题是"输入导向"的学习——看资料但没有明确的产出目标。本计划将学习模式转变为"产出导向"：每天都有明确的代码产出和验收标准。

  • 每天开始前，先看当日的【验收标准】，明确今天要做到什么
  • 先写测试/定义输出，再学原理和写代码（Test-Driven Learning）
  • 每天结束时必须有可运行的代码或可发布的内容，不允许"只看了没做"
  • 每周日的复盘日是强制输出日：博客 + GitHub 推送，用公开承诺倒逼坚持

9.2 每日学习节奏建议

时间段内容说明
通勤/午休（30min）原理学习（阅读文档/论文）利用碎片时间输入，不写代码
晚上第1小时实战编码（核心任务）精力最好时写最难的代码
晚上第2小时调试 + 笔记整理解决问题，记录学到的关键点
睡前（15min）回顾当日产出 + 明日计划确认验收标准是否达成
周末上午（3h）项目集中开发大块时间做需要连续思考的任务
周末下午（2h）博客写作 + 复盘输出倒逼输入，建立个人品牌

9.3 坚持激励机制

  • GitHub 贡献热力图：每天至少一次 commit，保持绿色连续
  • 博客发布节奏：每周至少 1 篇，30 天共 4 篇，建立技术影响力
  • 里程碑奖励：每完成一周给自己一个小奖励
  • 社群监督：在 AI 相关社群或公众号宣布你的 30 天计划
  • 进度可视化：在 GitHub 建 Learning 仓库，用 Markdown 记录每日进度

9.4 遇到困难时的应对

  • 原理看不懂：先跳过，用起来再说，很多概念在用的过程中自然理解
  • 代码写不出来：先找官方示例跑通，再逐步修改，不要从零硬写
  • API 调用出错：先检查 API Key、模型名称、参数格式，再看错误信息
  • 某天没时间：至少完成最小任务（15分钟），保持连续性比单日完成量重要
  • 进度落后：不要焦虑，优先保证项目产出，原理学习可以压缩，周末补
