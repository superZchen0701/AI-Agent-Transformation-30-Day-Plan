# DeepSeek Harness 模块分析笔记

## 一、项目定位

DeepSeek Harness 是一个插件化 Agent Runtime。

核心思想：

> Everything is a Plugin

目标：

-   构建可扩展 Agent 系统
-   支持多模型
-   支持工具生态
-   支持安全执行环境

# 二、Monorepo结构

主要模块：

    packages/
    ├── core
    ├── llm
    ├── mcp
    ├── plan
    ├── sandbox
    └── bundle

    apps/
    └── cli

# 三、核心模块分析

## 1. packages/core

核心 Agent 框架。

包含：

    core
    ├── agent
    ├── agent-loop
    ├── tools
    ├── session
    └── system-prompt

## 1.1 agent

职责：

-   Agent接口定义
-   Agent生命周期管理
-   Agent事件管理

## 1.2 agent-loop

职责：

实现智能体循环：

    Input
     |
    Context
     |
    LLM
     |
    Tool Call
     |
    Observation
     |
    Next Step

负责：

-   推理流程
-   工具调用
-   状态推进

## 1.3 session

负责：

-   对话历史
-   Event Log
-   上下文持久化

保存：

    User Message
    Assistant Message
    Tool Result
    System Event

## 1.4 tools

负责工具系统：

包括：

-   Tool Registry
-   Tool Schema
-   Tool Execution

流程：

    Agent
     |
    Tool Registry
     |
    Permission Check
     |
    Execute

# 四、packages/llm

LLM抽象层。

作用：

统一模型调用接口。

结构：

    Agent

     |

    LLM Adapter

     |

    DeepSeek API

优势：

Agent无需关心具体模型。

# 五、packages/mcp

MCP(Model Context Protocol)

作用：

连接外部工具。

结构：

    Agent

     |

    MCP Client

     |

    External MCP Server

应用：

-   GitHub
-   Database
-   Browser
-   企业系统

# 六、packages/sandbox

安全执行环境。

负责：

-   命令隔离
-   文件权限控制
-   代码执行

流程：

    Command
     |
    Policy
     |
    Sandbox Runtime
     |
    Result

# 七、packages/plan

规划模块。

作用：

将复杂任务拆解为：

    Goal

    ↓

    Plan

    ↓

    Steps

    ↓

    Execution

# 八、packages/bundle

插件组合层。

类似：

Agent运行时配置模板。

定义：

    默认插件集合

    +
    插件加载顺序

# 九、apps/cli

用户入口。

流程：

    CLI

    ↓

    Runtime Bootstrap

    ↓

    Load Bundle

    ↓

    Start Agent

    ↓

    Execute Task

# 十一、二次开发建议

如果基于 DeepSeek Harness 开发自己的 Agent：

## 新增能力

推荐：

    packages/extensions

而不是修改 core。

## 新增工具

扩展：

    core/tools

或开发 MCP Server。

## 企业应用接入

推荐：

    MCP Server

    +

    Custom Plugin

## 新增Agent能力

扩展：

    core/agent

# 十二、整体理解

DeepSeek Harness 可以理解为：

    Agent Runtime
    +
    Plugin System
    +
    LLM Layer
    +
    Tool Ecosystem
    +
    Sandbox
    +
    MCP

它不是简单的 Agent SDK，而是一个用于构建长期演化 Agent 系统的运行平台。
